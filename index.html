プライバシーポリシー — 文字起こしツール

最終更新日: 2026年4月23日

1. はじめに

「文字起こしツール」（以下「本拡張機能」）は、ブラウザタブの音声およびマイク音声をライブで文字起こしするChrome拡張機能です。また、保存済みの音声・動画ファイルからの文字起こしにも対応しています。文字起こしエンジンは2種類から選択できます。☁️ OpenAIのAPIによる高精度な文字起こし（APIモード）と、🖥️ Chrome内蔵の音声認識によるブラウザ内ローカル処理（オンデバイスモード・APIキー不要）に対応しています。サイドパネルおよびポップアップウィンドウで文字起こし結果を表示し、テキストの検索・コピー・エクスポート、オンデバイス翻訳機能、音声録音・画面録画機能、およびGoogleドキュメントへの自動書き込み機能を提供します。本プライバシーポリシーは、本拡張機能がユーザーのデータをどのように取り扱うかを説明します。

2. 収集するデータ

2.1 OpenAI APIキー

本拡張機能は、☁️ APIモードでの文字起こし機能を提供するために、ユーザーまたは管理者が提供するOpenAI APIキーを使用します。🖥️ オンデバイスモードではAPIキーは不要であり、取得・保存されません。APIキーは以下の方法で取得・保存されます。

  • ユーザーが直接入力するAPIキー（sk-形式）: ユーザーが設定画面で入力します。
  • 管理者が配布するアプリ専用キー（skt-形式）: 管理者がGoogle Admin Consoleのmanaged policyを通じて配布します。
  • 管理者がリモート配信するAPIキー: 組織管理者がGoogle Apps Script（GAS）Webアプリを通じて配布する場合、拡張機能が定期的にGAS WebアプリのURLにHTTP GETリクエストを送信してAPIキーを取得します（詳細は2.8項を参照）。

いずれの方法で取得したAPIキーも、ブラウザのローカルストレージ内にAES-GCM方式で暗号化して保存されます。アプリ専用キーは拡張機能内で復号され、元のAPIキーとしてOpenAIのAPIへの接続認証にのみ使用されます。

2.2 音声・映像データ

本拡張機能は、ユーザーが明示的に文字起こしを開始した場合に限り、以下の音声データを取得します。

  • ユーザーが共有を許可したブラウザタブの音声（PC音声）
  • ユーザーが有効化した場合のマイク音声

☁️ APIモード（ライブ文字起こし）の場合: これらの音声データはOpenAIのRealtime Transcription APIにWebSocket（WSS）経由で直接送信されます。音声データは本拡張機能の開発者のサーバーには一切送信されません。

🖥️ オンデバイスモードの場合: 音声データはブラウザ内のChrome内蔵音声認識エンジンによってローカルで処理されます。音声データはOpenAI APIを含む外部サーバーには一切送信されません。

ファイル文字起こしの場合: ユーザーが選択した音声・動画ファイルはブラウザ内でデコード・分割された後、OpenAIのWhisper APIにHTTPS経由で送信されます。ファイルデータは本拡張機能の開発者のサーバーには一切送信されません。元のファイルが変更されることはありません。

また、ユーザーが録音・録画オプションを有効にした場合、以下のファイル（WebM形式）がユーザーの端末にローカル保存されます。

  • 音声のみモード: PC音声およびマイク音声を含む音声録音ファイル
  • 音声＋画面モード: 画面共有で取得した映像とPC音声・マイク音声を含む画面録画ファイル

映像データ（画面共有の映像トラック）は、ユーザーが「音声＋画面」録画モードを選択した場合にのみ保持されます。映像データは録画ファイルのローカル保存にのみ使用され、OpenAI APIを含む外部サーバーには一切送信されません。「音声のみ」モードの場合、映像トラックは取得後直ちに破棄されます。

録音・録画ファイルは文字起こし停止時に自動的にダウンロードされ、ユーザーの端末内にのみ存在します。これらのファイルが外部に送信されることはありません。

2.3 文字起こし結果

☁️ APIモードではOpenAI APIから返された文字起こしテキスト、🖥️ オンデバイスモードではChrome内蔵音声認識エンジンが生成した文字起こしテキストが、ブラウザのローカルストレージ（chrome.storage.local）に保存されます。このデータはユーザーの端末内にのみ存在し、外部には送信されません（ユーザーがGoogleドキュメント連携を有効にしている場合を除く。詳細は2.7項を参照）。

2.4 設定データ

文字起こしエンジンの選択、言語設定、文字起こしモデル、区切り方、文字サイズ、フォント、テーマ、マイク使用の有無、マイクノイズリダクション設定、録画モード、Googleドキュメント連携設定などのユーザー設定は、ブラウザのローカルストレージに保存されます。

ユーザーが入力した「用語ヒント（プロンプト）」は、☁️ APIモードでの文字起こしの精度向上を目的としてOpenAI APIのセッション設定の一部として送信されます。🖥️ オンデバイスモードでは用語ヒントは使用されず、外部に送信されません。

拡張機能の内部動作に必要な一時的な状態情報（マイクタブの識別子、ポップアップウィンドウの状態など）は、ブラウザのセッションストレージに保存され、ブラウザを閉じると自動的に削除されます。

2.5 翻訳データ

本拡張機能は、Chromeブラウザに組み込まれたTranslator API（Chrome 138以降）を使用して、文字起こし結果のテキストを翻訳します。翻訳処理はすべてユーザーの端末上のオンデバイスAIモデルによって実行され、翻訳対象のテキストが外部サーバーに送信されることはありません。翻訳結果は文字起こし結果と同様にブラウザのローカルストレージに保存されます。

2.6 Googleアカウント情報

Googleドキュメント連携機能を使用する場合、ユーザーが明示的にログイン操作を行うと、GoogleのOAuth 2.0認証を通じて以下の情報を取得します。

  • メールアドレス: ログイン中のアカウントを識別・表示するために取得します
  • OAuth認証トークン（アクセストークン・リフレッシュトークン）: Google Docs APIへのリクエストを認証するために取得します

OAuth認証トークンはAES-GCM方式で暗号化してブラウザのローカルストレージに保存されます。メールアドレスは認証トークンとともに暗号化して保存されます。これらの情報は本拡張機能の開発者のサーバーには一切送信されません。

Googleドキュメント連携機能はオプションであり、ユーザーが有効にしない限りGoogleアカウントへのアクセスは一切行われません。

2.7 Googleドキュメント連携データ

ユーザーがGoogleドキュメント連携を有効にしてログインした場合、文字起こし結果のテキスト（翻訳結果を含む）がGoogle Docs APIを通じてユーザーが指定したGoogleドキュメントに書き込まれます。送信されるのはテキストデータのみであり、音声データ、映像データ、録音・録画ファイルがGoogleに送信されることはありません。

Googleドキュメントに書き込まれたデータは、Googleのサーバー上に保存されます。Googleドキュメント上のデータの管理（共有設定、削除など）はユーザー自身がGoogleドキュメントの標準機能で行います。

2.8 リモートAPIキー配信（組織管理者向け）

本拡張機能は、組織管理者がGoogle Apps Script（GAS）Webアプリを通じてOpenAI APIキーを一元配布できる機能を備えています。この機能が構成されている場合、以下の通信が行われます。

  • 通信方向: 拡張機能からGAS WebアプリへのHTTP GETリクエストのみです。
  • 送信データ: 組織管理者が利用状況を把握できるよう、Chromeプロファイルにログイン中のメールアドレスをクエリパラメータとしてGAS Webアプリに送信します。GAS Webアプリ側では、組織管理者がアクセスログ（日時・メールアドレス）をスプレッドシートに記録できます。メールアドレスの取得に失敗した場合はパラメータなしでリクエストが送信され、APIキーの取得は正常に動作します。メールアドレス以外のユーザーデータ（閲覧データ、音声データ、文字起こし結果など）は一切送信されません。
  • 受信データ: GAS Webアプリから返却されるのはAPIキー（文字列）のみです。実行可能なコード、スクリプト、またはプログラムロジックの取得・実行は一切行いません。
  • 通信頻度: 拡張機能の起動時に1回、およびその後定期的（約6時間間隔）にAPIキーの鮮度を確認するためにリクエストが送信されます。また、文字起こし開始時にキャッシュが一定時間（約1時間）以上経過している場合に再取得を行います。
  • 保存方法: 取得したAPIキーはAES-GCM方式で暗号化してブラウザのローカルストレージにキャッシュされます。送信したメールアドレスは拡張機能側では保存されません。
  • 通信先: Google Apps Scriptのホスティング基盤（script.google.com および script.googleusercontent.com）です。GAS WebアプリのURLは組織管理者が拡張機能の構成に埋め込みます。

この機能により、組織内のユーザーは個別にAPIキーを入力する必要がなくなります。ユーザーが設定画面で直接APIキーを入力した場合、そのキーがリモート配信のキーよりも優先して使用されます。

3. 収集しないデータ

本拡張機能は以下のデータを一切収集しません。

  • Googleドキュメント連携でのログイン時に取得するメールアドレスを除く、個人を特定できる情報（氏名、住所など）
  • ウェブ閲覧履歴、アクセスしたURL
  • ウェブページのコンテンツ
  • Cookie、位置情報、財務情報
  • 匿名の使用統計やアナリティクスデータ
  • 翻訳処理に伴う外部へのテキスト送信（翻訳はすべて端末内で完結します）
  • 🖥️ オンデバイスモード使用時の音声データの外部送信（音声認識はすべてブラウザ内で完結します）
  • Googleアカウントのパスワードやその他の認証情報（認証はGoogleのOAuth 2.0フローで処理され、本拡張機能はパスワードにアクセスしません）
  • リモートAPIキー配信の通信において、メールアドレス以外のユーザーデータ（閲覧データ、音声データ、文字起こし結果など）

4. データの使用目的

収集したデータは以下の目的にのみ使用されます。

  • OpenAI APIキー: ☁️ APIモードにおけるOpenAI Realtime Transcription APIおよびWhisper APIへの接続認証
  • 音声データ（☁️ APIモード）: OpenAI APIによるライブ文字起こし処理、およびWhisper APIによるファイル文字起こし処理
  • 音声データ（🖥️ オンデバイスモード）: Chrome内蔵音声認識エンジンによるブラウザ内ローカル文字起こし処理（外部送信なし）
  • 録音・録画ファイル: ユーザーが有効にした場合の音声記録または画面録画のローカル保存
  • 映像データ: ユーザーが「音声＋画面」録画モードを選択した場合の画面録画ファイルへの記録（外部送信なし）
  • 文字起こし結果: ユーザーへの表示、検索、コピー、エクスポート機能の提供、およびGoogleドキュメントへの書き込み（有効時のみ）
  • 用語ヒント: ☁️ APIモードでのOpenAI APIでの文字起こし精度の向上
  • 設定データ: ユーザーの設定の保持・復元
  • 翻訳データ: 文字起こし結果のオンデバイス翻訳表示、およびGoogleドキュメントへの書き込み（有効時のみ）
  • Googleアカウント情報: Google Docs APIへのリクエスト認証およびログイン状態の表示
  • Googleドキュメント連携: 文字起こし結果テキストのGoogleドキュメントへのライブ書き込み
  • リモートAPIキー配信: 組織管理者が配布するAPIキーの自動取得・キャッシュ（ユーザーの個別入力を不要にするため）、およびChromeプロファイルのメールアドレスを利用状況把握のためにGAS Webアプリに送信

5. データの共有・第三者への提供

☁️ APIモード: 音声データ（ライブ文字起こし時のストリーミング音声およびファイル文字起こし時の音声チャンク）、ならびにユーザーが設定した用語ヒントは、OpenAI, Inc.のAPIに直接送信されます。OpenAIによるデータの取り扱いについては、OpenAIのプライバシーポリシーをご確認ください。

🖥️ オンデバイスモード: 音声データはブラウザ内でローカル処理され、OpenAI APIを含む外部サーバーには一切送信されません。

映像データ（画面録画の映像トラック）はOpenAI APIを含む外部サーバーには送信されず、ユーザーの端末内でのローカル録画にのみ使用されます。

Googleドキュメント連携を有効にした場合、文字起こし結果のテキストがGoogle Docs APIを通じてGoogle, LLC（Alphabet Inc.）のサーバーに送信されます。Googleによるデータの取り扱いについては、Googleのプライバシーポリシーをご確認ください。Googleに送信されるのはテキストデータのみであり、音声データ、映像データ、録音・録画ファイルがGoogleに送信されることはありません。

リモートAPIキー配信機能において、拡張機能はGoogle Apps Scriptのホスティング基盤（script.google.com）にHTTP GETリクエストを送信します。このリクエストには、組織管理者が利用状況を把握するためにChromeプロファイルのメールアドレスがクエリパラメータとして含まれます。メールアドレスはGAS Webアプリ（組織管理者が管理するスプレッドシート）でのアクセスログ記録にのみ使用され、本拡張機能の開発者には送信されません。メールアドレス以外のユーザーデータは一切含まれません。GAS Webアプリから受信するのはAPIキー文字列のみです。

上記を除き、本拡張機能の開発者はユーザーのデータを第三者に共有、販売、転送することは一切ありません。

6. データの保存とセキュリティ

  • OpenAI APIキーはAES-GCM（256ビット）で暗号化してブラウザのローカルストレージに保存されます。リモート配信で取得したAPIキーも同様に暗号化してキャッシュされます。
  • アプリ専用キー（skt-形式）は、拡張機能内でAES-GCMにより復号され、復号後のAPIキーはメモリ上でのみ使用され永続的に平文で保存されることはありません。
  • Google OAuth認証トークンはAES-GCM（256ビット）で暗号化してブラウザのローカルストレージに保存されます。
  • ☁️ APIモードにおけるライブ文字起こしの音声データはWebSocket Secure（WSS）で暗号化して送信されます。
  • ファイル文字起こしの音声データはHTTPS（TLS）で暗号化して送信されます。
  • 🖥️ オンデバイスモードでは音声データはブラウザ内でローカル処理され、外部に送信されません。
  • Google Docs APIへの通信はHTTPS（TLS）で暗号化されます。
  • GAS Webアプリへの通信はHTTPS（TLS）で暗号化されます。
  • 文字起こし結果および設定データはブラウザのローカルストレージにのみ保存され、外部送信されません（Googleドキュメント連携が有効な場合を除く）。
  • 録音・録画ファイルはユーザーの端末にのみ保存され、外部に送信されません。
  • 映像データは録画ファイル内にのみ含まれ、外部に送信されません。
  • すべてのデータはユーザーの端末内にのみ存在します（Googleドキュメントに書き込まれたテキストを除く）。

7. リモートコードの不使用

本拡張機能はManifest V3に準拠しており、外部サーバーから実行可能なコードをダウンロード・実行することは一切ありません。すべてのプログラムロジックは拡張機能パッケージ内に含まれています。GAS Webアプリを含む外部サーバーから取得するのはデータ（APIキー文字列、API応答テキスト等）のみであり、eval()やその他の動的コード実行メカニズムは使用していません。🖥️ オンデバイスモードで使用するChrome内蔵音声認識エンジン（Web Speech API）はブラウザ自体に組み込まれた機能であり、外部からダウンロードされるコードではありません。

8. データの削除

ユーザーはいつでも以下の方法でデータを削除できます。

  • 拡張機能内の「クリア」ボタンで文字起こし履歴を削除
  • 設定画面でAPIキーを削除
  • Googleドキュメント連携の「ログアウト」ボタンでGoogle認証トークンを削除（ブラウザのローカルストレージから暗号化されたトークンが削除されます）
  • Googleドキュメントに書き込まれたテキストは、Googleドキュメントの標準機能で削除できます
  • 録音・録画ファイルはユーザーの端末に保存されるため、通常のファイル操作で削除できます
  • 拡張機能をアンインストールすることで、拡張機能が保存したすべてのデータ（リモート配信されたAPIキーのキャッシュおよびGoogle認証トークンを含む）が削除されます（端末にダウンロードされた録音・録画ファイル、およびGoogleドキュメントに書き込まれたテキストを除く）

9. Chrome Web Store Limited Use Policy への準拠

本拡張機能は、Chrome Web Store User Data Policyおよび Limited Use Requirements に準拠しています。取得したユーザーデータは、本拡張機能の単一の目的（☁️ APIモードおよび🖥️ オンデバイスモードによるライブ文字起こし、ならびにファイル文字起こし）を提供・改善するためにのみ使用されます。ユーザーデータを広告目的で使用すること、第三者に販売すること、信用力の判定に使用することはありません。Google OAuth 2.0を通じて取得したデータ（認証トークン、メールアドレス）についても同様に、本拡張機能の機能提供にのみ使用されます。

10. 子どものプライバシー

本拡張機能は13歳未満の子どもを対象としたものではなく、13歳未満の子どもから意図的に個人情報を収集することはありません。

11. 本ポリシーの変更

本プライバシーポリシーは必要に応じて更新されることがあります。重要な変更がある場合は、本ページの最終更新日を更新します。

12. お問い合わせ

本プライバシーポリシーに関するご質問は、Chrome Web Storeの拡張機能サポートページよりお問い合わせください。

Privacy Policy — Transcription Tool

Last updated: April 23, 2026

1. Introduction

"Transcription Tool" (hereinafter "this extension") is a Chrome extension that transcribes audio from browser tabs and microphone input live. It also supports transcription of saved audio and video files. Two transcription engines are available: ☁️ high-accuracy transcription via the OpenAI API (API mode), and 🖥️ local processing within the browser using Chrome's built-in speech recognition (on-device mode, no API key required). It displays transcription results in a side panel and a popup window, and provides text search, copy, export, on-device translation, audio recording/screen recording, and Google Docs integration features. This Privacy Policy explains how this extension handles user data.

2. Data We Collect

2.1 OpenAI API Key

This extension uses an OpenAI API key provided by the user or an administrator to deliver transcription functionality in ☁️ API mode. In 🖥️ on-device mode, no API key is required and none is obtained or stored. API keys are obtained and stored through the following methods:

  • User-entered API keys (sk- format): Entered by the user in the settings.
  • Administrator-distributed app-bound keys (skt- format): Distributed by administrators via Google Admin Console managed policy.
  • Remotely distributed API keys: When an organization administrator distributes keys via a Google Apps Script (GAS) Web App, the extension periodically sends HTTP GET requests to the GAS Web App URL to retrieve the API key (see section 2.8 for details).

Regardless of the method of acquisition, all API keys are encrypted using AES-GCM and stored in the browser's local storage. App-bound keys are decrypted within the extension and used solely for authenticating connections to the OpenAI API.

2.2 Audio and Video Data

This extension captures the following audio data only when the user explicitly initiates transcription:

  • Audio from the browser tab that the user has authorized for sharing (PC audio)
  • Microphone audio, if enabled by the user

☁️ API mode (live transcription): Audio data is sent directly to the OpenAI Realtime Transcription API via WebSocket Secure (WSS). Audio data is never sent to the extension developer's servers.

🖥️ On-device mode: Audio data is processed locally within the browser by Chrome's built-in speech recognition engine. Audio data is never sent to any external server, including the OpenAI API.

File transcription: Audio and video files selected by the user are decoded and split within the browser, then sent to the OpenAI Whisper API via HTTPS. File data is never sent to the extension developer's servers. The original file is not modified.

Additionally, if the user enables the recording option, the following files (WebM format) are saved locally on the user's device:

  • Audio-only mode: An audio recording file containing PC audio and microphone audio
  • Audio + Screen mode: A screen recording file containing video from screen sharing along with PC audio and microphone audio

Video data (the video track from screen sharing) is retained only when the user selects the "Audio + Screen" recording mode. Video data is used solely for local recording file storage and is never sent to any external server, including the OpenAI API. In "Audio-only" mode, the video track is discarded immediately after capture.

Recording files are automatically downloaded when transcription stops and exist only on the user's device. These files are never transmitted externally.

2.3 Transcription Results

In ☁️ API mode, transcription text returned from the OpenAI API, and in 🖥️ on-device mode, transcription text generated by Chrome's built-in speech recognition engine, are stored in the browser's local storage (chrome.storage.local). This data exists only on the user's device and is not transmitted externally (except when the user has enabled Google Docs integration; see section 2.7 for details).

2.4 Settings Data

User preferences such as transcription engine selection, language, transcription model, segmentation mode, font size, font family, theme, microphone usage, microphone noise reduction settings, recording mode, and Google Docs integration settings are stored in the browser's local storage.

The "terminology hints (prompt)" entered by the user are sent to the OpenAI API as part of the session configuration to improve transcription accuracy in ☁️ API mode. In 🖥️ on-device mode, terminology hints are not used and are not sent externally.

Temporary state information required for the extension's internal operation (such as microphone tab identifiers and popup window state) is stored in the browser's session storage and is automatically deleted when the browser is closed.

2.5 Translation Data

This extension uses the Translator API built into Chrome (Chrome 138 and later) to translate transcription text. All translation processing is performed entirely on the user's device using an on-device AI model, and the text being translated is never sent to any external server. Translation results are stored in the browser's local storage in the same manner as transcription results.

2.6 Google Account Information

When using the Google Docs integration feature, if the user explicitly performs a login action, the following information is obtained through Google's OAuth 2.0 authentication:

  • Email address: Obtained to identify and display the logged-in account
  • OAuth authentication tokens (access token and refresh token): Obtained to authenticate requests to the Google Docs API

OAuth authentication tokens are encrypted using AES-GCM and stored in the browser's local storage. The email address is stored encrypted together with the authentication tokens. This information is never sent to the extension developer's servers.

The Google Docs integration feature is optional; unless the user enables it, no access to the user's Google account is made.

2.7 Google Docs Integration Data

When the user enables Google Docs integration and logs in, transcription result text (including translation results) is written to the user's specified Google document via the Google Docs API. Only text data is transmitted; audio data, video data, and recording files are never sent to Google.

Data written to Google Docs is stored on Google's servers. Management of data in Google Docs (sharing settings, deletion, etc.) is performed by the user through the standard features of Google Docs.

2.8 Remote API Key Distribution (For Organization Administrators)

This extension includes a feature that allows organization administrators to centrally distribute OpenAI API keys via a Google Apps Script (GAS) Web App. When this feature is configured, the following communication occurs:

  • Communication direction: Only HTTP GET requests from the extension to the GAS Web App.
  • Data sent: To enable organization administrators to track usage, the email address of the Chrome profile's signed-in user is sent as a query parameter to the GAS Web App. The GAS Web App records access logs (timestamp and email address) in a spreadsheet managed by the organization administrator. If the email address cannot be obtained, the request is sent without the parameter and API key retrieval works normally. No other user data (browsing data, audio data, transcription results, etc.) is transmitted.
  • Data received: Only an API key (string) is returned from the GAS Web App. No executable code, scripts, or program logic is downloaded or executed.
  • Communication frequency: One request is sent when the extension starts, and periodic requests are sent approximately every 6 hours to check key freshness. An additional request may be sent before starting transcription if the cached key is older than approximately 1 hour.
  • Storage: The retrieved API key is encrypted using AES-GCM and cached in the browser's local storage. The email address sent in the request is not stored by the extension.
  • Communication destination: Google Apps Script hosting infrastructure (script.google.com and script.googleusercontent.com). The GAS Web App URL is embedded in the extension configuration by the organization administrator.

This feature allows users within the organization to use the extension without individually entering an API key. If the user enters an API key directly in the settings, that key takes priority over the remotely distributed key.

4. How We Use Data

Collected data is used solely for the following purposes:

  • OpenAI API Key: Authentication for connecting to the OpenAI Realtime Transcription API and the Whisper API in ☁️ API mode
  • Audio Data (☁️ API mode): Live transcription processing via the OpenAI API, and file transcription processing via the Whisper API
  • Audio Data (🖥️ On-device mode): Local transcription processing within the browser using Chrome's built-in speech recognition engine (no external transmission)
  • Recording Files: Local storage of audio recordings or screen recordings when enabled by the user
  • Video Data: Recording to screen recording files when the user selects "Audio + Screen" mode (never transmitted externally)
  • Transcription Results: Display, search, copy, and export functionality for users, and writing to Google Docs (when enabled)
  • Terminology Hints: Improving transcription accuracy via the OpenAI API in ☁️ API mode
  • Settings Data: Persisting and restoring user preferences
  • Translation Data: On-device translation and display of transcription results, and writing to Google Docs (when enabled)
  • Google Account Information: Authenticating requests to the Google Docs API and displaying login status
  • Google Docs Integration: Live writing of transcription result text to Google Docs
  • Remote API Key Distribution: Automatic retrieval and caching of API keys distributed by the organization administrator (to eliminate the need for individual user input), and sending the Chrome profile email address to the GAS Web App for usage tracking by the organization administrator

5. Data Sharing and Third-Party Disclosure

☁️ API mode: Audio data (streaming audio during live transcription and audio chunks during file transcription) and user-configured terminology hints are sent directly to OpenAI, Inc.'s API. For information on how OpenAI handles data, please refer to OpenAI's Privacy Policy.

🖥️ On-device mode: Audio data is processed locally within the browser and is never sent to any external server, including the OpenAI API.

Video data (the video track from screen recording) is never sent to any external server, including the OpenAI API, and is used solely for local recording on the user's device.

When Google Docs integration is enabled, transcription result text is sent to Google, LLC (Alphabet Inc.) servers via the Google Docs API. For information on how Google handles data, please refer to Google's Privacy Policy. Only text data is sent to Google; audio data, video data, and recording files are never sent to Google.

For the remote API key distribution feature, the extension sends HTTP GET requests to Google Apps Script hosting infrastructure (script.google.com). These requests include the Chrome profile email address as a query parameter to enable usage tracking by the organization administrator. The email address is used solely for access log recording in the GAS Web App (a spreadsheet managed by the organization administrator) and is never sent to the extension developer. Other than the above, the extension developer does not share, sell, or transfer user data to any third parties.

6. Data Storage and Security

  • The OpenAI API key is encrypted with AES-GCM (256-bit) and stored in the browser's local storage. API keys retrieved via remote distribution are also encrypted and cached in the same manner.
  • App-bound keys (skt- format) are decrypted via AES-GCM within the extension; the decrypted API key is used only in memory and is never persistently stored in plaintext.
  • Google OAuth authentication tokens are encrypted with AES-GCM (256-bit) and stored in the browser's local storage.
  • Audio data for live transcription in ☁️ API mode is transmitted using WebSocket Secure (WSS) encryption.
  • Audio data for file transcription is transmitted using HTTPS (TLS) encryption.
  • In 🖥️ on-device mode, audio data is processed locally within the browser and is not transmitted externally.
  • Communication with the Google Docs API is encrypted via HTTPS (TLS).
  • Communication with the GAS Web App is encrypted via HTTPS (TLS).
  • Transcription results and settings are stored only in the browser's local storage and are not transmitted externally (except when Google Docs integration is enabled).
  • Recording files (audio recordings and screen recordings) are stored only on the user's device and are never transmitted externally.
  • Video data is contained only within recording files and is never transmitted externally.
  • All data resides solely on the user's device (except for text written to Google Docs).

7. No Remote Code Execution

This extension complies with Manifest V3 and does not download or execute any executable code from external servers. All program logic is contained within the extension package. Only data (API key strings, API response text, etc.) is retrieved from external servers, including the GAS Web App. No eval() or other dynamic code execution mechanisms are used. The Chrome built-in speech recognition engine (Web Speech API) used in 🖥️ on-device mode is a feature built into the browser itself and is not code downloaded from external sources.

8. Data Deletion

Users can delete their data at any time through the following methods:

  • Use the "Clear" button within the extension to delete transcription history
  • Remove the API key from the settings
  • Use the "Logout" button in the Google Docs integration settings to delete Google authentication tokens (encrypted tokens are removed from the browser's local storage)
  • Text written to Google Docs can be deleted using the standard features of Google Docs
  • Recording files (audio recordings and screen recordings) are saved on the user's device and can be deleted through standard file management
  • Uninstalling the extension deletes all data stored by the extension (including cached remotely distributed API keys and Google authentication tokens), except for recording files already downloaded to the device and text written to Google Docs
